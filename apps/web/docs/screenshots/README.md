# Screenshots

Place screenshots here with the following filenames:

- `dashboard-light.png`, `dashboard-dark.png`
- `notes-light.png`, `notes-dark.png`
- `vault-light.png`, `vault-dark.png`

The main README references these; they will automatically appear once files are added.

Recommended dimensions: 1440×900 or 1920×1200, PNG, compressed.
